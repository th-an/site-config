3. Append-Only Law

4. Honest Boundaries

Unmatched transfers stay in the UNRESOLVED queue with reasons, never silently booked.

5. Synthetic Demo

All demo records derive from seeded scripts; zero client or live secrets permitted.

🔐 Security & Privacy Architecture Zero-Leak Design

RFC 5297 AES-SIV Field Encryption

Sensitive fields (addresses, labels) encrypt deterministically using vetted cryptography primitives. Exact-match DB queries remain functional without storing keys in the repository (CRYPTO_TAX_ENC_KEY env var).

Tamper-Evident HMAC Attestation

Computations seal via HMAC-SHA256 digests over canonical calculation JSON bound to engine and jurisdiction versions (CRYPTO_TAX_ATTEST_KEY).

GDPR Privacy by Design

Operates strictly on synthetic demo data and recorded fixtures. Because historical rates never re-query and rows never mutate, zero personal data exists at rest.

Statutory Immutability (§147 AO)

DAC8 report snapshots enforce 10-year statutory retention via trigger-locked SQLite append-only tables, preventing accidental or malicious row alterations.
