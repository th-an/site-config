Universal Engineering Takeaways Across Protocols

1. Tool Output Is Ground Truth

Language models invent mechanisms to explain tool results. Always reproduce with raw invocations; treat chat narrative as a hypothesis to verify, not evidence.

2. Server-Enforced Trust Contracts

Bake fidelity and anti-hallucination rules directly into the MCP server instructions field rather than relying on per-conversation prompt adherence.

3. Test the Exported Surface

Sample-driven testing with dirty CSVs and exported tool calls catches missing runtime dependencies and silent validation masking before deployment.
